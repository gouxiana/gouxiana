我关注 Unity 交互内容、虚拟现实体验、游戏机制和生成式人工智能。习惯从需求与体验出发，参与场景与资产制作、交互逻辑、界面反馈、运行调试和结果整理，把一个想法推进到可运行、可展示的项目。
